# Logo assets

- `source-logo-black-original.png`: 用户提供的透明背景原稿，保持不变。
- `logo-mark-black.png`: 规范化留白后的纯黑标志。
- `logo-header-light-142033.png`: 浅色界面标题标志。
- `logo-header-dark-F3F7FC.png`: 深色界面标题标志。
- `app-icon-blue.png`: 未启用的备用图标方案。
- `app-icon-blue.ico`: 未启用的备用图标方案（ICO）。
- `archive/`: 已停用的旧版图标，仅用于留档。

当前使用规则：新 Logo 只显示在软件内大标题“AI 媒体标签工具”的左侧；Windows 窗口、任务栏和 EXE 继续使用原程序图标。

运行 `tools/build_logo_assets.py <source-logo.png>` 可以从黑色透明原稿重新生成全部派生文件。
